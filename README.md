# Fundación Osasuna · Escuela 2026-27

App para los monitores: **Hoy**, **Sedes**, **Tajonar** y **Monitores**.

- Este repositorio solo tiene el diseño de la app (HTML, iconos). **No contiene ningún dato personal.**
- Los datos están en Google Sheets y los sirve un Google Apps Script que solo responde con el PIN correcto.
- Para editar datos: cambia las Google Sheets. La app se actualiza sola.
- Para cambiar el PIN: en Apps Script (Code.gs), cambia `PIN` y crea una nueva versión de la implementación.
